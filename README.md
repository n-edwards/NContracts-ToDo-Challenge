# NContracts QA Challenge

Playwright test suite for the [TodoMVC demo app](https://demo.playwright.dev/todomvc).

Completed by Nicholas Edwards, candidate for Quality Advocate role.

Initial repo structure and code generated by Claude Code. Reviewed and cleaned up by Nicholas. Promted to simplify and improve tests, remove redundancies, add comments, and clear errors after initial test runs.

## Setup

```bash
npm install
npx playwright install --with-deps
```

## Run tests

```bash
# Full suite (headless)
npx playwright test  # default
npm test  # alternative

# With browser visible
npm run test:headed

# Interactive UI mode
npm run test:ui  # recommended to veryify passing tests, step by step
```

## View HTML report

```bash
npx playwright show-report
```
